## 4. Temuan

### [F-01] Masuk dengan PIN mustahil: RPC `verifikasi_pin_perangkat` dipanggil aplikasi tetapi tidak ada di database
- **Tingkat:** K-2
- **Artefak:** `aplikasi/src/lib/auth.ts:176`; tidak ada definisi di `supabase/migrations/*` (53 berkas)
- **Klaim yang dilanggar:** `docs/ROADMAP.md` T2-02 `[x]` "masuk dengan PIN … bukti 2026-09-22" (dan T2-04 "alur masuk pegawai"); `docs/TECH_SPEC.md` §7 (jalur masuk lewat Edge Function + RPC)
- **Bukti:**
  - `grep -rn "verifikasi_pin_perangkat" aplikasi/src supabase` → **1 baris** (`aplikasi/src/lib/auth.ts:176`), **0** di `supabase/`.
  - Probe `pg_proc`: `select count(*) from pg_proc where proname='verifikasi_pin_perangkat'` → **0**; yang ada hanya `verifikasi_pin` yang isinya menuntut `auth.uid()` (identitas pengguna sudah masuk).
  - `grep -rn "signInWithPassword\|signInWithOtp\|setSession\|refreshSession" aplikasi/src` → **0 baris**; satu-satunya panggilan auth Supabase adalah `signOut` (`auth.ts:235`). Artinya klien **tidak pernah** mendapatkan token sesi, sehingga jalur Edge Function (yang butuh header `Authorization`) juga buntu.
  - Uji aplikasi hijau karena `auth.ts:141-171` punya cabang **simulasi**: bila `klienSupabase()` null (env `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` kosong — memang kosong di Vitest), fungsi mengembalikan `LOGIN_SUKSES` tanpa memanggil RPC. 84 berkas/671 tes hanya menyentuh cabang itu.
- **Skenario gagal:** pegawai menekan "Masuk" pada aplikasi nyata → `supabase.rpc('verifikasi_pin_perangkat', …)` → PostgREST membalas galat tidak ditemukan → layar masuk selalu gagal; dua lapis setelahnya (Edge Function + `verifikasi_pin`) tak pernah tersentuh. Pemilik yang mengikuti dokumen akan menyimpulkan PIN-nya salah, padahal fiturnya belum pernah tersambung.
- **Dugaan penyebab:** RPC baru direncanakan di `0018`/`0030` (nama yang mendarat: `verifikasi_pin` + `perangkat_sah`), sementara klien sudah menulis pemanggilan nama lain; tidak ada pemeriksa yang membandingkan nama RPC klien dengan katalog PostgreSQL (pemeriksa `peta-ui.py` hanya membaca migrasi).
