# Gambar referensi kiriman pemilik

Folder ini **khusus untuk gambar referensi yang pemilik kirim sendiri** (contoh: 10 gambar pada 2026-09-16 —
Grill & Co., Burger House, Burger Bliss, Burger District, CoachPro, dsb).

Kenapa folder terpisah? Supaya jelas mana **contoh dari pemilik** dan mana **hasil pencarian agent**
(ada di folder induk `docs/desain/referensi/`, berkas 01–13).

## Cara memasukkan gambar (3 langkah, tanpa koding)

1. Buka halaman folder ini di GitHub (repo **Resto-Barokah**, folder `docs/desain/referensi/pemilik`).
2. Klik tombol **Add file** → **Upload files**.
3. **Seret/seret-lepas** semua gambarmu ke kotak unggah → tulis pesan singkat (mis. "referensi desain dari pemilik")
   → klik **Commit changes**.

**Nama berkas: bebas, tidak perlu dirapikan.** Kirim apa adanya (`.jfif`, `.jpg`, `.png` semua boleh) —
agent yang akan merapikan nama & ukurannya.

Bingung menentukan tempat? **Taruh saja di mana pun** (bahkan di halaman utama repo) — agent akan memindahkannya
ke folder ini.

## Setelah gambar masuk, agent akan mengerjakan ini

1. **Memeriksa** semuanya bisa dibuka & mencatat isinya satu per satu (tanpa ada yang terlewat).
2. **Merapikan**: memberi nama berurut yang bermakna (mis. `P01-katalog-burger-terang.jpg`), mengecilkan ukuran
   berkas bila terlalu besar (agar repo tetap ringan & cepat dibuka).
3. **Membuat papan perbandingan** (`papan-referensi-pemilik.jpg`) agar mudah dilihat berdampingan.
4. **Memperbarui catatan**: `Sumber.md`, `PENILAIAN_REFERENSI.md`, dan `RENCANA_DESAIN_UI.md` — termasuk pola mana
   yang dipakai, mana yang tidak, dan alasannya.

## Catatan penting

- **Repo ini privat** — gambar di sini hanya untuk **bahan diskusi & inspirasi internal**, tidak ditampilkan
  ke pengguna dan **tidak ikut masuk ke aplikasi** yang dirilis.
- Desain aplikasi Resto Barokah tetap **dibuat sendiri (orisinil)**; contoh hanya untuk mempelajari pola tata letak.
- Bila pemilik tahu sumber gambar (nama situs/desainer), boleh disebutkan di pesan unggahan — akan dicatat sebagai
  keterangan sumber. Kalau tidak tahu, tidak masalah.
