# agent-skills-hub — catalog index (sumber: Input-Pengguna/agent-skills-hub-main.zip 35M, ~42k files di repo meta)

> **Catatan template:** File zip asli `Input-Pengguna/agent-skills-hub-main.zip` **tidak ikut ter-copy** ke repo baru. Yang ikut adalah **CATALOG.md** index 30 sample di folder ini (hemat 35M bengkak). Untuk browse/install di repo baru, gunakan:
> `npx skills find <keyword>` atau `npx skills add <owner/repo> --skill <nama>` — jangan `unzip -l Input-Pengguna/...` (path itu hanya ada di repo meta, tidak ada di template).

Full hub 42k files tetap sebagai zip di repo meta sebagai provenance; di template hanya index agar agent tahu tanpa bengkak.
