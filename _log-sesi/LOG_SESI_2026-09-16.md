### 2026-09-16 — KEJADIAN PLATFORM: git kotak kerja ter-reset di tengah sesi (ditangani tanpa kehilangan data)
- **Gejala:** `git push` ditolak (`non-fast-forward`), padahal commit lokal hanya 1 langkah di depan. Reflog hanya memuat 3 catatan (clone → checkout → 1 commit) padahal sesi ini sudah membuat 13+ commit.
- **Penyebab (fakta terverifikasi):** direktori git di kotak kerja **ter-reset** di tengah sesi (branch kembali ke `253d129` "Input Sistem"), sementara berkas-berkas hasil kerja tetap utuh di working tree (dipulihkan dari snapshot) → commit terakhir lahir di atas basis lama, sehingga bercabang dari riwayat di GitHub (yang berakhir di `ab3f6dc`).
- **Penanganan (tanpa menimpa apa pun):** (1) `git fetch` + `git ls-remote` untuk tahu kebenaran keadaan remote; (2) `git diff --stat ab3f6dc HEAD` membuktikan perbedaannya **hanya** 17 berkas kerjaan baru (tidak ada pekerjaan lama yang hilang/tertimpa); (3) `git reset --soft ab3f6dc` (branch digeser, isi berkas tidak disentuh) lalu commit ulang dengan pesan sama → riwayat linear di atas commit GitHub; (4) push berhasil `ab3f6dc..372044c`.
- **Pelajaran untuk sesi berikutnya:** sebelum push, **selalu** bandingkan `git ls-remote --heads origin` dengan `git log --oneline -1`. Bila push ditolak: **jangan** `--force`, jangan menimpa — diagnosa dulu dengan `git reflog` + `git diff --stat <remote> HEAD`. Hash commit lama (28a213d) tetap ada di reflog sebagai cadangan.
